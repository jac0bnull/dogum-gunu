# 🎂 Doğum Günü Sürprizi

HTML, CSS ve JavaScript kullanılarak hazırlanmış interaktif doğum günü web sitesi.

## 🚀 Canlı Önizleme

🎁 **[Doğum Günü Sürprizini Aç](https://jac0bnull.github.io/dogum-gunu/)**

🎉 **[Alternatif Doğum Günü Sayfası](https://jac0bnull.github.io/dogum-gunu/dogum-gunu.html)**

## 💻 Bilgisayarda Çalıştırma

1. Repoyu ZIP olarak indirin.
2. Dosyaları klasöre çıkartın.
3. `index.html` dosyasına çift tıklayın.
4. Site tarayıcınızda açılacaktır.

## 📁 Proje Dosyaları

- `index.html` — Ana giriş sayfası
- `dogum-gunu.html` — Doğum günü sayfası
- `music.mp3` — Müzik dosyası

## 🛠️ Teknolojiler

HTML, CSS ve JavaScript.
